# شب پوکر

حساب‌دار سادهٔ بازی حضوری، فارسی، قابل نصب و قابل استفاده بدون اینترنت.

- نام‌ها به ترتیب نشستن و یک مبلغ ورودی مشترک ثبت می‌شوند.
- دیلر بعد از ثبت هر دست می‌چرخد؛ اجبار کوچک ۱٬۰۰۰ و بزرگ ۲٬۰۰۰ تومان است. در بازی دونفره دیلر اجبار کوچک را دارد. افراد با موجودی صفر تا شارژ دوباره کنار گذاشته می‌شوند.
- پایان هر دست، مبلغ باخت هر نفر را در پنجره وارد کنید و برنده را تیک بزنید. مبلغ باخت شامل اجبار پرداخت‌شده است؛ برنامه آن را دوباره کم نمی‌کند. عدد خالی یعنی صفر.
- چند برنده یعنی تقسیم مساوی مجموع باخت‌ها. تومان باقی‌مانده به ترتیب نشستن بعد از دیلر می‌رسد. برای دست کاملاً مساوی، همهٔ افراد حاضر را برنده انتخاب کنید.
- شارژ فقط در موجودی صفر و دقیقاً به اندازهٔ ورودی است. برداشت فقط از موجودی اضافه بر ورودی اولیه انجام می‌شود؛ موجودی پس از برداشت نباید کمتر از ورودی اولیه شود.
- سود و بدهی هر نفر = موجودی فعلی + برداشت‌ها − همهٔ ورودی‌ها. شارژ مجدد سود محسوب نمی‌شود و برداشت، سود ثبت‌شده را تغییر نمی‌دهد.
- هر زمان «حساب نهایی / پایان بازی» را بزنید، بدهکارها، طلبکارها و انتقال‌های لازم نمایش داده می‌شوند. پایان بازی، نتیجه و دست‌ها را ذخیره می‌کند.

داده‌ها فقط در مرورگر همان دستگاه ذخیره می‌شوند؛ پاک‌کردن داده‌های مرورگر آن‌ها را پاک می‌کند. اطلاعات نسخهٔ قبلی در کلید اصلی خود نگه داشته می‌شود. بازی‌های ثبت دست‌به‌دست و چیپ مجازی در صورت داشتن موجودی معتبر به نسخهٔ ساده منتقل می‌شوند.

## اجرا و بررسی

Node.js 22 یا جدیدتر:

```sh
npm test
npm run serve
```

نشانی اجرای محلی: http://localhost:5173

## انتشار و نصب

مخزن: https://github.com/sinahdp/poker-night

نشانی GitHub Pages پس از انتشار موفق: https://sinahdp.github.io/poker-night/

گردش‌کار `.github/workflows/pages.yml` تست‌ها را اجرا و فقط فایل‌های وب را روی GitHub Pages منتشر می‌کند. در تنظیمات مخزن، بخش Pages، منبع انتشار باید GitHub Actions باشد.

روی Android، نشانی منتشرشده را با Chrome باز کنید و «نصب برنامه» یا گزینهٔ Install app مرورگر را بزنید. روی iPhone، در Safari گزینهٔ Share سپس Add to Home Screen را انتخاب کنید. برای آماده‌شدن حالت آفلاین، اولین بار با اینترنت باز کنید.

این اپ پرداخت بانکی انجام نمی‌دهد؛ مبالغ تسویه، سود و باخت خالص بین بازیکن‌ها هستند.
